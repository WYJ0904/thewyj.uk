## 4. 证据结构与计数规则

每次执行建立只增不覆盖的目录，记录 candidate/source/APK/Web/API/device 身份，实际开始和结束时间，attempt、stage、status、失败原因和执行者。每条真实事件使用会话随机盐派生的账户/事件标识；只保留必要的 package/profile、金额最小单位、方向、状态及版本。原始标题、正文、聊天、Cookie/token、OCR 截图、支付凭证/银行卡号不进入 Git 或远端日志。

需要截图时，仅在单独授权和必要裁剪/脱敏范围内采集测试画面；仍可能包含隐私的原件由所有者本地保管，报告使用脱敏副本和摘要。不得为了取证打开正式数据库或完整通知库。

状态仅使用 PASS / FAIL / NOT TESTED / BLOCKED，附覆盖范围。环境未就绪、JUnit 跳过、仅断言前 checkpoint、被 watchdog 强制终止、网络未持久化均不计 PASS。首个失败永久保留；后续复验增加新 attempt，不能覆盖失败或更改历史时间。10 次必须是 10 个完整独立真实事件；合成注入、桌面浏览器、Preview、UI 截图本身均不计入。
