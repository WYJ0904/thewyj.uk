# DS Task 09｜Aeris 会员保留和财务对账

Task 09 使用独立 D1 表保存合户状态、授权记录、审计和对账凭据。迁移 `0045_ds_account_merge_bridge.sql` 新增这些表，Task 13 会员、Task 16 账目和 Task 21 收款生命周期仍由原模块维护。

## 执行凭据

- 仅专用本地运行或精确匹配的 `aeris-task09-*.pages.dev` 与 `ds-task09-*.pages.dev` Preview 注册可调用。环境隔离标记须同时存在于 D1。每位参与者有按稳定主体绑定的测试名单记录。
- 复用现有已认证 HMAC backchannel、nonce 和绑定来源的 Aeris Grant。注册、财务读取和提交复查当前 Grant、逐个 Task 07 证据、账户与安全版本、有效安全邮箱、审核挂起及特权角色。
- 各账户须以自己的未撤销 Grant，单独确认 `ds_finance_reconciliation_v1`。最近登录窗口为 5 分钟，授权最长 10 分钟，绑定 Merge ID 和版本。账户所有权证明本身不能触发财务读取。源业务快照查询和提交条件同时校验全部授权。
- 冲突审核需要合成环境名单、逐合户审核指派、有效的管理员角色及最近通过 TOTP 登录签发的 Grant。审核者须独立于该合户。可作出的决定是保留各原交易。普通用户没有审批或强制继续的接口。
- 服务端补偿只接受已认证客户端与原 Merge ID、版本。撤销凭据拒绝迟到的注册或提交。补偿停用合户投影，保留源账本和执行审计。

## Task 13 会员

会员适配器存档原 grant、来源、原到期时间和关联的履约订单。不同来源的同一有效权益取永久或最晚的原到期日。过期、取消和未来启用的权益归档。保留账户和原账户的显式禁止项在计算时生效。管理员单独授权项没有自动继承。

保留结果由 DS 合户状态页显示。适配器未接入 Aeris 原生访问控制及履约路径，原生服务权限继承仍需对应业务模块与 Task 10 决策。付款、结算、退款和会员授予记录由原账本继续持有。

## Task 16 与 Task 21 对账

所有者、原交易 ID、整数最小单位文本、货币指数、发生时间、入账时间、修订、同步版本、设备、导入批次、原始凭证引用和退款联系保存在 Aero D1 内。原始记录与去重后的规范引用同时保留。DS 仅接收经核验的摘要和已脱敏的审核状态。逐案审核员可读取必要金额单位及证据摘要。

自动匹配要求经过可信适配器确认的提供商、提供商账户作用域、唯一操作引用及金额、币种、精度、交易方向和父操作一致。Task 16 通知引用、Task 21 未验证候选、金额或时间相同都只能提供审核线索。当前分支的提供商签名适配器尚无真实渠道账户绑定与交易持久关联。测试只向隔离库注入来源事实。未来真实事实只能由经过批准的业务适配器提供。

金额求和使用 `BigInt`，按币种、指数及类型分列，退款、转账和未分类记录单列。缺少可信精度的交易进入审核并保留原单位。对账输出没有写入 Task 16 账目。超过已实现的快照上限时，任务停留在待对账状态，原账本不受影响。
