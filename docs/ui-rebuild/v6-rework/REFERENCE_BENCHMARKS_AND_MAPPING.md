# Aeris V6 UI/UX Rework — Reference Benchmarks & Mapping

This document records the live external product study performed via browser inspection and documentation review before refactoring Aeris V6.3. All designs respect upstream licenses (Apple/Samsung proprietary, Linear proprietary, Cloudflare Docs, IT-Tools GPL-3.0, Actual Budget MIT/reference UI, n8n Sustainable Use, Motion MIT) — clean-room structural, compositional, and interaction borrowing only; zero proprietary or copyleft code was copied into the repository.
