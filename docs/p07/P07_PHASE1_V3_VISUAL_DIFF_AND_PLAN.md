### 4. 受真实业务或安全合同约束、不做机械照搬的项

- **侧栏“通知”与“学习统计”独立路由**：当前真实路由体系中学习统计内聚于 `/language` 学习工作区、通知归档内聚于 Android 端及 `/finance` 待核实入口，侧栏不虚构不存在的 404 页面，改用真实有效路由（`首页`、`学习`、`免费试用`、`财务`、`工具箱`、`工作流`、`文件`、`会员`、`账户`）。
- **侧栏“管理后台”入口**：参考图静态展示了“管理后台”，但实际产品必须严格遵守权限合同——访客与普通用户下隐藏（`hidden`），仅在 `isAdmin(account)` 为真时显示。
- **卡片与摘要数据真实性**：未登录访客明确显示 `演示` 标记或诚实功能说明；已登录账户严格读取真实学习记录、错题数、账本同步余额、传输队列与最近工具，空数据时展示真实空状态，绝不伪造“复习 12 题”或虚假金额。
